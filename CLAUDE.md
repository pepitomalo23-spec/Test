# pj.fire

Static web app (no build step) deployed on Vercel, backed by Supabase. The user writes in Spanish; code comments are in Spanish.

- Structure and load order: see README.md. `js/` files are classic scripts sharing the global scope, loaded in the order listed at the end of `index.html`. Top-level code in a file may only use what earlier files declared; `js/arranque.js` must stay last.
- After editing anything in `css/`, `js/` or `datos/`, run `node scripts/versionar.mjs` and commit the updated `index.html` (and the js that references a changed `datos/` file). CI (`.github/workflows/comprobar.yml`) fails if a `?v=` is stale.
- `sw.js` precaches `index.html` plus every `css/`/`js/` file it links; versioned files are served cache-first without revalidation, so a stale `?v=` means users keep the old file.
- Edge functions in `supabase/functions/` are deployed as-is; keep the repo copy identical to what is deployed. `callejero-sync`, `backup-db` and `push-reminders` pin `jsr:@supabase/supabase-js@2.117.1` (the latest JSR release failed to bundle).
- Supabase stops auto-granting Data API access to new tables in `public` from 2026-10-30. Every migration that creates a table must also grant it explicitly (in the same migration, next to its RLS policies): `grant select, insert, update, delete on public.<table> to authenticated;` (only what the app needs; `anon` only if it is read without signing in) and `grant select, insert, update, delete on public.<table> to service_role;` (Edge Functions). Existing tables keep their grants.
- Estudio › Temario (`js/temario-guiado.js`): the content is written by Claude directly in `public.temario_temas` (via SQL, `service_role`), not in the repo. The row format (`pasos`, `preguntas`) and the HTML boxes allowed in each step are documented at the top of that file. Read `temario_progreso.dudas` and `temario_intentos` to see what the user didn't understand or failed. Videos only from `https://www.youtube-nocookie.com/embed/…` and images only from `data:`, the project's Supabase or `upload.wikimedia.org` (CSP in `vercel.json`); diagrams as inline SVG using CSS variables (`var(--text)`, `var(--orange)`…) so they work in both themes.
- Temario content goes article by article: each step starts with `<div class="tg-articulo" data-art="N"></div>` (optionally `data-ap="D-H"`), which `privado.temario_rellenar()` fills with the official BOE text cached in `privado.boe_laula` (see `supabase/migrations/20261112_temario_boe.sql`), followed by `<div class="tg-explica">Explicado fácil</div>` and the explanation. Illustrations (generated with Higgsfield, converted to WebP ≤1024 px) live in `assets/temario/<ley>/` and are referenced as `assets/temario/...` from the HTML.
